Features

Built for real moderation.

Every feature you actually need, nothing you don't. Nova stays out of the way until you need it.

⚔️

Full mod suite

Ban, kick, mute, timeout, warn, purge, lock — all with slash and prefix commands that work the same way.

🤖

Smart auto-mod

Three configurable filters — anti-spam, anti-links, anti-caps — with escalating punishment at warn thresholds.

📋

Case tracking

Every action creates a numbered case with the moderator, reason, and timestamp. Full history per user.

🌐

Live dashboard

Server owners log in with Discord and manage settings, view infractions, and configure auto-mod in real time.

🔒

Global blacklist

Nova staff can blacklist users globally — they're auto-banned from all Nova-protected servers the moment they join.

⏱️

Temp punishments

Set a duration on bans and mutes. They expire automatically — no manual cleanup needed.

📣

Mod logging

Every action is posted to your designated log channel with full context and embed formatting.

⚙️

Per-server config

Custom prefix, mod role, mute role, warn thresholds, and escalation actions — configured per server.
